# Liquid Orb Studio — 사용 안내

[繁體中文](../README.md) · [English](README.en.md) · [日本語](README.ja.md)

Liquid Orb Studio는 브라우저에서 실행되는 실시간 WebGPU 액체 유리 구체 편집기입니다. 프리셋을 선택하고 모양과 움직임을 조절한 뒤 현재 디자인을 공유하거나 내보낼 수 있습니다.

[온라인 앱 열기](https://ntwnbfgzpb-cell.github.io/liquid-orb-studio/)

![Liquid Orb Studio 인터페이스 미리보기](../generated_images/exec-e32ce8f6-df03-4c18-8a5e-8d577bc00602.png)

## 주요 기능

- 6개의 액체 유리 구체 프리셋
- 세 가지 색상, 속도, 난류 및 소용돌이 실시간 조절
- 크기, 표면 디테일, 비대칭, 굴절, 두께 및 색 분산 조절
- 글로우 강도와 반경 조절
- 애니메이션 일시 정지·재생 및 FPS 확인
- 현재 설정이 포함된 공유 URL 생성
- 현재 화면을 PNG 이미지로 저장
- 독립 실행형 WebGPU HTML 페이지 내보내기
- SwiftUI, Metal 및 사용 안내가 포함된 Apple ZIP 내보내기

## 사용 방법

1. 왼쪽 **Presets** 패널에서 원하는 스타일을 선택합니다.
2. 오른쪽 패널에서 색상, 움직임, 형태, 유리 및 글로우를 조절합니다.
3. **일시 정지**로 애니메이션을 멈추거나 **초기화**로 현재 프리셋의 기본값을 복원합니다.
4. **공유**를 누르면 현재 설정을 유지하는 URL이 클립보드에 복사됩니다.
5. **스크린샷**으로 PNG를 저장하거나 **내보내기**에서 독립형 웹 페이지 또는 Apple ZIP을 생성합니다.

## 사용 환경

- 최신 Google Chrome 또는 Microsoft Edge를 권장합니다.
- 브라우저와 장치가 WebGPU를 지원해야 합니다.
- 구체가 표시되지 않으면 브라우저 하드웨어 가속을 켜고 브라우저 및 그래픽 드라이버를 업데이트하세요.
- 모바일과 태블릿에서도 반응형 인터페이스를 사용할 수 있지만 WebGPU 지원 여부는 장치와 브라우저에 따라 다릅니다.
