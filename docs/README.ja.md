# Liquid Orb Studio — 使い方

[繁體中文](../README.md) · [English](README.en.md) · [한국어](README.ko.md)

Liquid Orb Studio は、ブラウザ上で動作するリアルタイム WebGPU 液体ガラスオーブエディターです。プリセットを選び、見た目や動きを調整して、設定の共有や書き出しができます。

[オンライン版を開く](https://ntwnbfgzpb-cell.github.io/liquid-orb-studio/)

![Liquid Orb Studio の画面プレビュー](../generated_images/exec-e32ce8f6-df03-4c18-8a5e-8d577bc00602.png)

## 主な機能

- 10 種類の液体ガラス／クリスタル素材プリセット
- 3 色の配色、速度、乱流、渦のリアルタイム調整
- サイズ、表面ディテール、非対称性、屈折、厚み、色分散、平滑度の調整
- 反射、コースティクス、グロー、ブルーム、範囲の調整
- アニメーションの一時停止・再開と FPS 表示
- 現在の設定を保持した共有 URL の作成
- PNG スクリーンショットの保存
- 単体で開ける WebGPU HTML ページの書き出し
- SwiftUI、Metal、導入メモを含む Apple ZIP の書き出し

## 操作方法

1. 左側の「Presets」から好みのスタイルを選びます。
2. 右側のパネルで色、動き、形状、ガラス、グローを調整します。
3. 「一時停止」でアニメーションを止め、「リセット」で現在のプリセットの初期状態に戻します。
4. 「共有」を押すと、現在の設定を含む URL がクリップボードにコピーされます。
5. 「スクリーンショット」で PNG を保存し、「書き出し」から Web ページまたは Apple ZIP を作成します。

## 動作環境

- 最新版の Google Chrome または Microsoft Edge を推奨します。
- ブラウザと端末が WebGPU に対応している必要があります。
- オーブが表示されない場合は、ブラウザのハードウェアアクセラレーションを有効にし、ブラウザとグラフィックドライバーを更新してください。
- スマートフォンやタブレットでもレスポンシブ画面を利用できますが、WebGPU の対応状況は端末とブラウザにより異なります。
