# Liquid Orb Studio — User Guide

[繁體中文](../README.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

Liquid Orb Studio is a real-time WebGPU liquid-glass orb editor. Choose a preset, customize its appearance and motion, then share or export your design directly from the browser.

[Open the live app](https://ntwnbfgzpb-cell.github.io/liquid-orb-studio/)

![Liquid Orb Studio interface preview](../generated_images/exec-e32ce8f6-df03-4c18-8a5e-8d577bc00602.png)

## What you can do

- Start with ten liquid-glass and crystal material presets.
- Adjust three colors, animation speed, turbulence, and swirl.
- Control size, surface detail, asymmetry, refraction, thickness, dispersion, and smoothness.
- Fine-tune reflection, caustics, glow, bloom, and radius.
- Pause or resume the animation and monitor FPS.
- Create a shareable URL containing the current settings.
- Download the current view as a PNG image.
- Export a standalone WebGPU HTML page.
- Export an Apple ZIP containing SwiftUI, Metal, and setup notes.

## How to use it

1. Choose a style from the **Presets** panel on the left.
2. Use the controls on the right to adjust colors, motion, shape, glass, and glow.
3. Select **Pause** to freeze the animation or **Reset** to restore the current preset.
4. Select **Share** to copy a URL that preserves the current settings.
5. Select **Snapshot** to download a PNG, or open **Export** to create a standalone Web page or Apple ZIP.

## Requirements

- The latest Google Chrome or Microsoft Edge is recommended.
- Your browser and device must support WebGPU.
- If the orb does not appear, enable browser hardware acceleration and update your browser and graphics driver.
- The responsive interface works on mobile devices and tablets, but WebGPU availability depends on the device and browser.
